# AR Planet Explorer

An augmented reality app that shows a model of the solar system and lets you
view the planets in your own space, with information about each planet.

This is my first AR application, built as a Week 1 practice project for the
Computer Graphics module.

- **Platform:** Android (ARCore)
- **Tools:** Unity 6 (6000.6.6f1), AR Foundation
- **Purpose:** Learn the Unity and AR workflow before building my final
  AR educational app (AR DSA Educational App)

## Features

- 3D solar system placed in the real world using the phone camera
- Information about each planet
- [Add what you can do in the app, e.g. rotate, scale, tap a planet to see its details]

## How to run

1. Open the project in Unity 6 (6000.6.6f1) with Android Build Support installed.
2. Switch the build platform to Android.
3. Connect an ARCore-supported Android phone with USB debugging on.
4. Choose **Build and Run**.
